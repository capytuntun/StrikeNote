# StrikeNote
>[!note]
>有鑑於HackMD越來越爛，故自行用AI寫了一個StrikeNote，以符合自己的筆記需求，這個筆記軟體是以Markdown為基礎的筆記，同時支援生成OSCP、OSEP、LPT\CPENT跟Virtual Hacking Lab的筆記模板，並且支援生成資安院攻防演練模式的報告


裝好 Node.js 後，在資料夾中執行：
```
node server/server.js
```

預設網址為 http://localhost:8080
需要一個 MariaDB（連線資訊用 `DB_*` 環境變數指定，見 `deploy/env.example`）。首次啟動會建立 `admin` 帳號並把隨機密碼印在終端機（或用 `ADMIN_PASSWORD` 指定），首次登入時要求更改。部署到 Raspberry Pi、從舊版 SQLite 搬資料：見 `deploy/README.md`

## 筆記模式
主要有三種筆記模式，可以對應到不同的功能
- 一般筆記模式
- 證照範本
- 資安院報告模式
### 一般筆記模式
具備一般md的基礎語法與功能，圖片也是直接拖拉上去就可以顯示出來，其中callout採用的是github的書寫語法。
```
> [!NOTE]  
> Highlights information that users should take into account, even when skimming.

> [!TIP]
> Optional information to help a user be more successful.

> [!IMPORTANT]  
> Crucial information necessary for users to succeed.

> [!WARNING]  
> Critical content demanding immediate user attention due to potential risks.

> [!CAUTION]
> Negative potential consequences of an action.
```
![callout](docs/callout.png)

除了 GitHub 的 `> [!NOTE]` 寫法，也支援 CodiMD / HackMD 的 `:::` 容器：`:::info … :::` 會產生和 `> [!NOTE]` 完全一樣的提示框。對應關係：`info→note`、`success→tip`、`danger→caution`、`warning→warning`（`note/tip/important/warning/caution` 也可直接寫在 `:::` 後）。可加標題如 `:::info 重點`；編輯器輸入 `/info`、`/success`、`/danger` 可快速插入。

程式碼區塊只依你標明的語言上色（例如 ```` ```bash= ````，`=` 表示顯示行號，`=10` 可指定起始行號）；沒標語言就是純文字，不會自動猜語言。工具列的「▤ Code」、`/code` 與 ``` 後的語言自動完成都預設帶 `=`。

也支援 CodiMD / HackMD 的 `[toc]`：獨立一行寫上 `[toc]`，預覽就會在該處依筆記裡的 H1～H3 標題自動產生可點擊的目錄（編輯器裡輸入 `/toc` 也可插入）。匯出 PDF 時仍使用封面後方附頁碼的目錄頁，內文中的 `[toc]` 不會重複輸出。

### 檔案、PDF 與網址預覽
- 圖片、PDF 和任何檔案都可以貼上、拖進編輯器，也可以按工具列的「檔案」或輸入 `/file` 挑檔案。圖片直接顯示；PDF 可以直接預覽 `![名稱](pdf:…)`，或只顯示成檔案連結 `[名稱](pdf:…)`；其他檔案是一個下載連結 `[名稱](file:…)`。
- 滑鼠移到 PDF 上會出現「檔案｜預覽」切換鈕；移到獨佔一行的網址上會出現「連結｜預覽卡片」。
- **圖片加黑框**：報告裡的截圖底色常常跟紙一樣白，整張糊在頁面上。滑鼠移到預覽的圖片上，除了「✎ 標註」還會出現「▢ 黑框」，點一下就給那張圖加上一圈細黑框，再點一下拿掉。狀態存在 markdown 裡（`![說明](img:…#frame)`），所以預覽、PDF 匯出、電子書都會照著顯示，整段複製到別篇筆記也跟著走。
- 網址預覽卡片寫成 `{%preview https://… %}`（或輸入 `/preview`），會顯示網頁標題、摘要與縮圖；這些資訊由伺服器去抓，主機不能對外連線時設 `LINK_PREVIEW=0`。
- 左下角「檔案管理」是整頁的畫面（網址 `#files`，跟垃圾桶一樣佔滿右邊、側邊欄還開著，右上角的 × 或 Esc 回首頁），列出所有上傳過的檔案、各自用在哪些筆記，也可以直接上傳——升級成一個小雲端硬碟：可以「新增資料夾」整理檔案（跟筆記的資料夾完全分開），把電腦裡的檔案直接拖進畫面或某個資料夾就上傳進去，檔案可以重新命名、用「搬移到資料夾」或直接拖曳搬進資料夾／麵包屑。刪除資料夾不會連著把裡面的檔案刪掉（檔案本身沒有垃圾桶）——裡面的東西會先搬到上一層。

### 標籤
任何一篇筆記（包括 trello 看板、start.me 頁、文件、drawio、關聯分析這些沒有 Markdown 內文的）都可以加標籤：首頁或區域頁那一列的 ⋯ → 「標籤…」、側邊欄右鍵、trello 磚與 start.me 頁面選單裡都有，空白或逗號分開，`#` 可打可不打。列上會顯示小籤片；首頁的「標籤」區與 `#標籤` 篩選會把所有區域（小說除外）有這個標籤的筆記都列出來，內文裡的 `#標籤` 和這裡加的算在一起。隨筆打開後，內文裡的網址、`[[筆記]]`、`#標籤` 會在下面列成可以點的籤片。

### 共用
筆記右上角的「分享」。裡面有兩件事：**指定某幾個人**（輸入帳號，給檢視者或編輯者），以及底下的**一般存取權**——兩列寫得明明白白的選項，不用點開才知道還有另一個：

- **限制**：只有我和我指定的人可以開啟（預設）。
- **網站內所有人**：這個網站上任何登入的人都能開啟。右邊可以選「可以檢視」或「可以編輯」，**打開時預設是可以編輯**（共用出去通常就是要一起弄），想改成唯讀隨時可以換。

選了就立刻生效，沒有「儲存」。開放出去的筆記會在首頁與區域頁的清單上帶一個地球標記，滑過去會說是可以檢視還是可以編輯——設定完對話框就關了，清單上沒標記的話等於沒辦法知道自己到底開放了哪幾篇。

**一次設定很多篇**：在首頁（或側邊欄）把要開放的筆記勾起來，批次列上的「共用」可以一次把一般存取權套到全部勾選的筆記；已經打開某一篇時，它的分享對話框底下也會多一個「同時套用到選取的其他 N 篇筆記」。批次模式只處理一般存取權，不做「指定某幾個人」——那件事對一整批筆記沒有意義。

「網站內所有人」指的是這個站上有帳號而且已經登入的人，不是網際網路上的任何人。要給**沒有帳號的人**看，用下面的公開連結。小說區的筆記不管怎樣都不能共用，伺服器會直接擋掉。

### 公開連結（分享給沒有帳號的人）
分享對話框最下面有一段「公開連結（沒有帳號也能看）」，按「管理公開連結…」→「建立分享連結」，就會得到一個 `https://你的網站/s/一長串亂數` 的網址（會自動複製）。任何拿到網址的人**不用帳號、不用登入**就能讀這篇筆記，圖片、嵌入的 drawio 圖表與關聯分析都在，可以直接用瀏覽器列印或存成 PDF。

- **唯讀**。拿到網址的人只能看，不能改，也拿不到這個站的任何其他東西。沒有「匿名也能編輯」這回事——那等於把存檔功能開給任何拿到網址的人。
- **要不要自動更新，每個連結自己設定**。建立連結時旁邊有「自動更新」的勾選（預設勾著），建好之後每個連結那一列也有，隨時可以改。
  - **勾著**：你之後改了筆記，停手約 8 秒（或切到別篇時）連結上的內容就會跟著更新。如果剛改完就關掉分頁，連結上會停在舊的那一版，下次打開分享對話框它會告訴你「連結上還是舊的內容」。
  - **沒勾**：連結停在你最後一次按「更新內容」的那一版，筆記怎麼改都不會動到它——適合把某個時間點的版本交給別人看，自己繼續改。要更新的時候按那一列的「更新內容」。
  - 把一個落後的連結重新勾回自動更新，它會當場更新成現在的內容。
- **可以設期限**（7／30／90 天或不設），一篇筆記可以有好幾個連結（給不同的人不同的期限），每個都能看開了幾次。
- **取消分享**後網址立刻失效；把筆記丟進垃圾桶連結也會打不開，還原回來又能開；筆記永久刪除，連結一起消失。
- 只有筆記的擁有者能建立、更新或取消——被分享的人就算有編輯權也不行。小說區的筆記不能開公開連結。
- 有公開連結的筆記在首頁與區域頁的清單上有一個橘色的連結標記（在網站內共用的地球標記旁邊），滑過去會說明。

技術上跟電子書的公開連結是同一套：連結上放的是打包好的一整頁 HTML（快照），不是筆記本身，所以拿到網址的人碰不到 API；那一頁也被瀏覽器的沙箱隔開，碰不到你的登入狀態。備份會帶著公開連結一起走，還原回來同一個網址照樣能開。

### 備份與還原
右上角帳號選單 → 「備份與還原」。「下載備份 zip」會把你所有的筆記（每篇一個 `.md`，照資料夾放好）、上傳過的圖片與檔案、版本歷史、分享設定、電子書與垃圾桶裡的筆記打包成一個 zip；管理員可以改選「整個站台」，連所有使用者帳號（含密碼雜湊）與註冊設定一起帶走，之後在一台全新的機器上還原就能整站復原。還原時上傳同一個 zip：會先顯示這份備份的內容再由你確認；缺的會補回來、已經有的預設不動，勾「覆蓋」才會用備份裡的內容取代現有筆記（覆蓋前會先留一份版本）。

### 系統監控（管理員）
右上角帳號選單 → 「系統監控」（原本的「儲存空間」）。即時顯示主機的 CPU、記憶體、負載、溫度（樹莓派有的話）、磁碟剩餘，以及 StrikeNote 伺服器自己的程序用量、帳號數、登入中的人數、正在編輯的筆記與連線數，每 5 秒更新一次，附最近 10 分鐘的走勢線；另有磁碟讀寫速度（Linux 的 /proc/diskstats；走勢線以最近十分鐘最快的那一刻為滿格）。底下還是每個帳號用了多少空間的那張表。只有管理員看得到，而且只有數字——不會顯示任何筆記內容。

### 開新分頁
首頁、區域頁、側邊欄、搜尋結果與隨筆卡片裡的筆記、資料夾、電子書，還有筆記裡的 `[[連結]]` 與 `#標籤`，都可以用滑鼠中鍵（按滾輪）在新分頁打開；筆記裡指向外部網站的連結一律開新分頁。隨筆卡片上的連結直接點就能用，不會變成打開卡片。

### 排序
側邊欄搜尋框旁、首頁清單右上角的「排序」可以選手動排序、名稱、建立時間、最近更新，兩邊共用同一套。手動排序時直接拖拉筆記或資料夾就能調整順序，順序存在伺服器上，換電腦也一樣。左邊的清單和首頁是同一套拖拉：可以把筆記從側邊欄直接拖到首頁的資料夾方框裡，也可以反過來從首頁拖回側邊欄的資料夾。

### 證照範本
目前既有的模板有OSCP、OSEP、LPT\CPENT、Vurtual Hacking Lab
![callout](docs/report.png)

點擊後可以自動生成相對應的模板，讓打OSCP時只需要把相對應的東西填進去就可以，點擊右上方PDF按鈕可以下載成PDF。

### 資安院報告的 PDF：一步一頁
資安院報告匯出 PDF 時，每個「步驟」都從新的一頁開始，所以一步就是一頁、不會有兩步擠在同一頁、也不會從中間被切斷。步驟裡的圖片會限制高度，整張截圖不會被頁尾切掉。步驟本身真的比一整頁還長（例如貼了一大段掃描輸出）時，它會照常往下一頁接續——不會為了「不切到」而把超出的內容吞掉。

### 四個獨立區域
側邊欄「新增」下方多了幾個跟一般筆記分開放的區域，各自有自己的筆記和資料夾，不會出現在首頁或側邊欄的筆記樹裡（「看板」在下一節）：

- **課程筆記**、**知識區**：跟首頁一樣可以建資料夾、開筆記，只是獨立的一頁，方便把準備考試或整理彙整的筆記跟平常的滲透測試筆記分開放。
- **課程筆記可以直接放檔案**：在資料夾裡按「上傳檔案」（或把檔案拖進頁面），PPTX、PDF、影片或任何檔案都會跟筆記放在同一個資料夾，分成「筆記」「檔案」兩段。PDF、MP4／WebM 影片、音訊與圖片點開就能在站內看（影片可以拖時間軸），PPTX 之類瀏覽器開不了的會給下載。圖片檔在清單裡直接顯示縮圖，滑鼠移到縮圖上會浮出較大的預覽。
- **便條紙**：課程筆記的資料夾右上角按「便條紙」就貼一張，直接在卡片上打字、自動儲存，可以換六種顏色，貼在資料夾頁面最上面；丟到垃圾桶一樣可以還原。
- **課程筆記的頁面跟「所有筆記」長得一樣**：資料夾方框右上角的「⋮」、筆記列的勾選框、釘選、改標題、「⋯」選單、排序鈕都跟首頁一樣（知識區、小說也是）；拖放也跟首頁一樣：筆記、上傳的檔案、便條紙（拖上方的色帶）可以拖進資料夾或拖回上層，資料夾和筆記可以拖曳排序，也可以直接從電腦把檔案拖到某個資料夾方框上傳進那個資料夾。在課程筆記裡點進資料夾、打開筆記後按瀏覽器的「上一頁」，會回到筆記所在的資料夾，再按一次往上一層。
- **多行編輯（多游標）**：跟 HackMD 一樣。按住 Alt 拖曳可以選一整欄（拖過的每一行各一個游標），Alt 點一下在那裡加一個游標（再點一下拿掉），Ctrl+Alt+↑/↓ 在上下行加游標，Ctrl+D 一個一個選起相同的字；接著打字、刪除、貼上都會同時作用在每個游標上（貼上的行數剛好等於游標數時，一個游標貼一行）。Esc 或點一下回到單一游標。中文輸入法、Ctrl+Z 復原、自動存檔都照常。
- **多人同時編輯**：把筆記分享給別人（「分享…」給可編輯權限，或開放給站上所有人），大家可以同時打開同一篇一起改，彼此的字大約 0.2 秒內出現（經過 Cloudflare 會再久一點）。上方會顯示誰也在看這篇，編輯區裡看得到每個人的游標和名字。兩個人改同一行、甚至同一個位置，兩邊打的字都會留下；只有改到完全相同的那幾個字時才以後存的為準。
- **全選與刪除**：首頁、課程筆記（知識區、小說）的筆記清單標題右邊有「全選／取消全選」，旁邊緊接著一顆「刪除」；課程筆記的「檔案」清單也有同樣兩顆。勾了幾項，刪除鈕上就寫幾項（「刪除 3 篇」），沒勾的時候是灰的；按下去會先問一次，然後把**這一段勾起來的**移到垃圾桶（保留期內可以復原）。要移動、共用，或連資料夾一起刪，用側邊欄的批次列。
- **匯入 .md（圖片一起匯）**：側邊欄最下面的「匯入 .md」可以一次選多個檔（.md 連同它用到的圖片一起選），或匯入整個資料夾（連子資料夾一起）。匯進去的位置就是你現在所在的地方：在課程筆記的某個資料夾裡匯入，就建在那個資料夾；在首頁就是所有筆記（或你正在看的資料夾）；在隨筆就變成隨筆。選單最下面會寫出會匯到哪裡。文章裡的圖片會自動處理好：相對路徑的圖片（`![](images/x.png)`、`<img src>`、參考式連結）跟內嵌的 base64 圖片都會上傳成站上的圖片，連結一併改寫，同一張圖被好幾篇用到也只會上傳一次；PDF 變成站內的 PDF，其他附件變成檔案連結。找不到檔案的圖片會原樣保留，程式碼區塊裡的連結不會被動到。標題取 YAML front matter 的 `title` 或第一個標題。外部網址的圖片瀏覽器抓不到（站台只允許同源圖片），會留著原本的連結——那種請用下面的命令列工具。沒有被任何一篇用到的檔案，只有匯進**課程筆記**時會一起變成檔案。
- **一整個資料夾批次匯入（命令列）**：`npm run import-md -- --dir ./out --url https://你的網址 --user 你的帳號 --password 密碼`。適合請 Claude Code 之類的工具把網站抓下來轉成一堆 .md 之後整批搬進來：除了上面那些，它還會**自動下載外部網址的圖片**再上傳（是在你自己的電腦上抓，不是叫伺服器去抓）。常用選項：`--area course`（匯到課程筆記）、`--into "第一週/講義"`（匯到哪個資料夾底下）、`--files all`（沒被引用到的檔案也一起匯，限課程筆記）、`--skip-existing`（重跑不會變兩份）、`--dry-run`（只看會做什麼，不連伺服器）、`--no-remote`、`--flat`。`--help` 有完整說明。
- **側邊欄跟著區域切換**：進到課程筆記、知識區、小說或隨筆，左邊的樹就只顯示那個區域的資料夾和筆記（最上面標出是哪個區域），打開那個區域裡的筆記時也一樣；回到首頁就是所有筆記。從側邊欄新增的筆記和資料夾會建在目前的區域裡，拖放也不會把東西拖進別的區域。大檔案會自動切塊上傳、有進度條，斷線會從中斷的那一塊接續；單檔上限由 `UPLOAD_MAX_BYTES` 決定（預設 1 GiB）。檔案可以改名、移動、丟垃圾桶；從垃圾桶永久刪除時檔案本體一起刪掉（除非別篇筆記還在用它）。
- **隨筆**：像 Google Keep 一樣的卡片牆，上方「記點什麼…」直接打字，關閉或點外面就成一張卡片，點卡片可以直接編輯，離開自動存檔。卡片可以釘選、上色、封存。內容是純文字，不走 Markdown：打什麼就顯示什麼（`#` 不是標題、換行就是換行），只有網址、`[[筆記]]`、`#標籤` 會變成連結。「新清單」或 ⋮ → 顯示勾選框是 Keep 式的清單：一列一個勾選框，Enter 新增、勾完的集中在「已完成」下面。圖片在卡片最上面，編輯時在上方一列可以 ✕ 掉。
- **小說**：放你自己寫的小說，需要再輸入一次目前帳號的密碼才能進去——這個解鎖只在瀏覽器這一頁有效，重新整理或關掉分頁都要再輸一次；而且伺服器本身在密碼確認之前也不會把這個區域的筆記送到瀏覽器，不是單純把畫面藏起來而已。

**所有筆記、課程筆記、知識區之間可以互相搬筆記**：筆記列的「⋯」選單或右鍵選單裡有「換區域…」，選好要搬到哪個區域、要放進那個區域的哪個資料夾（或最上層）就完成了。小說跟隨筆不開放這個功能——小說是為了保護才特別隔開的，隨筆本來就沒有資料夾的概念。

### 文件（所見即所得）
新增 → 文件。像 Google 文件的編輯器：上面一條工具列（復原重做、樣式「一般文字／標題 1–4／引言」、字型、字級、粗體／斜體／底線／刪除線、文字顏色與螢光筆、連結、圖片、對齊、項目符號與編號、縮排、表格、分隔線、清除格式），下面一張白紙，打字就是最後看到的樣子，不用寫 Markdown。停手半秒自動存檔，右上角顯示「已儲存」與字數。圖片可以貼上、拖進來或按工具列插入；Ctrl+K 插連結、Ctrl＋點連結開新分頁、Tab 縮排。字型有標楷體、新細明體；「分散對齊」連最後一行也撐滿（跟「左右對齊」不同）。紙上面有尺規（公分）：拖兩端的邊界標記改頁邊界，拖 ▲ 改段落左縮排、▼ 改首行縮排。表格的直格線可以拖，只動相鄰兩欄的寬度。標題、版本、分享、PDF 跟一般筆記一樣在最上面那一列；PDF 與預覽會照排版印出來。只有讀取權限的人看到的是不能編輯的頁面。

### trello（看板）
側邊欄「知識區」下面的「看板」，照著 [Trello](https://trello.com/) 做的：

- **看板頁**：一格一格有底色的磚是你的看板，最後一格「建立新看板」——跟 Trello 一樣先選背景、再填標題（沒有標題不能建立）。磚上按右鍵或 ⋯ 可以改名、換背景、移到垃圾桶。
- **列表與卡片**：橫向一排列表，每個列表一欄卡片。「＋ 新增卡片」展開輸入框，Enter 一張接一張、Esc 收起；最右邊「＋ 新增另一個列表」也一樣。列表標題點一下就地改名，⋯ 選單有複製列表、左右搬、排序卡片、封存。卡片和列表都可以拖——卡片可以拖到別的列表。
- **卡片正面**：標籤色條、標題、徽章——到期日（過期紅、24 小時內黃、完成綠）、有描述的圖示、待辦清單完成數／總數（全部完成變綠）。
- **卡片背面**（點一下卡片）：標題、「在列表「X」中」、標籤、到期日（可以勾完成）、描述（Markdown，點了才變輸入框）、待辦清單（進度條、勾選、新增、刪除項目）。右欄「新增至卡片」：標籤（Trello 的十個顏色，可以改名、新建）、待辦清單、到期日；「動作」：移動（選列表和位置）、複製、封存——封存之後才有「刪除」，跟 Trello 一樣。
- **已封存的項目**：看板右上角那顆按鈕，列出封存的卡片和列表，可以送回看板或刪除。「變更背景」是 Trello 的九個底色加六個漸層。
- 看板的標題在看板上點一下就能改，最上面那一列的標題也同步；版本、分享、PDF 跟一般筆記一樣在最上面。一個看板就是一篇筆記（內容是一段 ````board` 的 JSON），所以版本歷史、備份、搜尋、垃圾桶都照舊；在別篇筆記或 PDF 裡會畫成靜態的看板。

### start.me（起始頁）
側邊欄「看板」下面的「起始頁」，照著 [start.me](https://start.me/) 做的書籤起始頁：

- **最上面一列**：頁面分頁（可以有好幾頁，點切換、雙擊改名、「頁面」選單裡改背景顏色、欄數、顯示或隱藏搜尋框、移到垃圾桶；「＋」新增一頁），中間是搜尋框（Google／Bing／DuckDuckGo，Enter 開新分頁搜尋）。
- **幾欄小工具**（2–5 欄）：書籤小工具是一排排 favicon＋名稱的連結，點了開新分頁；底下「＋ 新增書籤」貼上網址就會自己抓標題和圖示（名稱可以自己填），表單留著繼續貼下一個；滑過書籤有編輯／刪除。便條小工具是一塊自由打字的文字，停手就存。
- 小工具可以拖到別欄、換順序，書籤可以在小工具之間拖；小工具標題點一下改名，⋯ 選單可以左右搬欄或刪除；每欄底下「＋ 新增小工具」。
- 一頁起始頁就是一篇筆記（內容是一段 ````startpage` 的 JSON），版本歷史、備份、搜尋、垃圾桶都照舊；在別篇筆記或 PDF 裡會畫成靜態的欄位與書籤。

### 關聯圖
側邊欄左下角的「關聯圖」是整頁的力導向圖：把所有筆記的 `[[反向連結]]` 跟 `#標籤` 畫成一張網，拖曳節點、滾輪縮放，左上角有縮放鈕、右下角可以重置視圖。

**點一下節點，跟它有關的會亮起來**：那顆和直接相連的節點維持原樣，其餘整片調暗，連出去的線加粗，頂欄會寫「選了誰、有幾個相關」。這個highlight是釘住的，滑鼠移開也不會散掉（滑到別顆上是暫時預覽，移開就回到選取的那顆）；再點同一顆、點空白處或按 Esc 取消。就算把「顯示名稱」關掉，選取與相關的那幾顆名字還是看得到——點下去就是為了知道相關的是「哪幾篇」。**要開啟筆記（或用標籤篩選）是雙擊。**上方的「顯示名稱」可以把每個節點的名字一次全開或全關（關掉之後滑到節點上還是看得到，圖很密的時候比較看得出結構），選擇會記住。從某篇筆記進來的話，按「返回」會回到那篇筆記。

### drawio
新增 → drawio。站內自己做的基本繪圖工具，版面照 [draw.io](https://www.drawio.com/) 的樣子：上面選單列與工具列、左邊圖形、中間畫布、右邊格式面板。標題、版本、分享、PDF 跟一般筆記一樣在最上面那一列。拿來畫流程圖、網路架構圖、攻擊路徑圖這類「框框加箭頭」的圖。只做基本的功能，不是 draw.io 本尊——沒有圖層、群組、圖庫，也不能開 `.drawio` 檔。

- **放圖形**：點一下左邊的圖形會放到畫布中央，或直接拖到想放的位置。有矩形、圓角矩形、文字、橢圓、正方形、圓形、膠囊、菱形、平行四邊形、六邊形、三角形、圓柱（資料庫）、雲、文件、人。
- **我的圖示**：左邊最下面那一區。按「上傳」（或把圖片檔直接拖進來）加入自己的圖示——主機、防火牆、廠商 Logo 之類，PNG／JPG／GIF／WebP／SVG，每個 2 MB 以內。上傳一次，之後**每一張圖都能用**，用法跟其他圖形一樣：點一下放到畫布中央，或拖到想放的位置；雙擊可以在圖示下面加文字，也可以拉連線。把圖片檔拖到畫布上，會加進圖示庫並直接放在那裡。**圖示庫只有你自己看得到**；不過圖分享出去的話，對方看得到畫在那張圖上的圖示（不然圖會缺一塊），其他沒用到的他看不到，也動不了你的圖示庫。滑到圖示上按右上角的「×」可以從圖示庫移除——已經畫在圖裡的不受影響。
- **網路設備**：左邊「網路設備」那一區有 27 個內建的圖示——路由器、交換器、防火牆、入侵偵測／WAF、負載平衡器、無線基地台、數據機、通道（VPN／Tunnel，一根水管）、網際網路、伺服器、機架伺服器、資料庫、NAS、網站、郵件伺服器、虛擬機、桌上型電腦、筆電、終端機／攻擊機、手機、印表機、網路攝影機、IoT 裝置、使用者、攻擊者、加密／VPN、金鑰／帳密。用法跟其他圖形一樣，文字寫在圖示下面；選起來之後用右邊的配色可以整個換顏色（例如把被打下來的主機改成紅色）。滑到圖示上會顯示它的名稱。
- **拉連線**：滑鼠移到圖形上，邊上會出現四個藍點，從藍點拉到另一個圖形就接起來了；之後搬動圖形，線會跟著走。拉到空白處放開也可以，線的那一頭就停在那裡。左邊「連線」裡的是單獨一條線（直線、箭頭、雙箭頭、虛線、折線、曲線）。
- **改文字**：雙擊圖形或連線，或選起來直接打字。Ctrl+Enter 或點別的地方收起來，Esc 取消。雙擊空白處可以直接打一段文字。
- **改樣子**：選起來之後在右邊的面板改——配色、填色、線條顏色與粗細、虛線、字的大小顏色粗體對齊；連線可以換成直線／折線／曲線，兩頭各自要不要箭頭。「排列」裡有位置大小、移到最前最後、多選之後的對齊。
- **選取**：點一下選一個，Shift+點多選，在空白處拖曳框選，Ctrl+A 全選。拉四個角的控制點改大小。
- **對齊輔助線**：拖曳或縮放時，邊或中線快對上別的圖形就會吸過去，並畫一條虛線告訴你對上了哪一條（比格線優先）。
- **等距分佈**：選三個以上的圖形，右邊「排列」或「調整」選單裡的「水平／垂直等距分佈」把最外面兩個固定、中間的排到每個間距一樣。
- **旋轉**：選一個圖形，拖右上角外面那個圓點繞著轉（靠近 15° 的倍數會吸過去，按住 Shift 一律每 15°，按住 Alt 完全自由），或在「排列」裡直接填角度、按「順時針／逆時針 90°」。連線會接在轉過的邊上。
- **分頁**：畫布下面那排是頁面，跟 draw.io 一樣——「＋」新增一頁、點切換、雙擊改名、右鍵有複製／搬移／刪除（刪除可以復原）。預覽、PDF、電子書、嵌到別篇筆記裡都是每一頁一張圖、頁名寫在上面；PNG／SVG 匯出的是目前這一頁。
- **右鍵選單**：在圖形或連線上按右鍵，有「移到最前／上移一層／下移一層／移到最後」（圖形疊在一起時決定誰在上面）、編輯文字、剪下／複製／貼上／再製／刪除；在空白處按右鍵是貼上（貼在游標那裡）、全選、符合視窗、格線。右鍵按住拖曳仍然是平移畫布。鍵盤：Ctrl+] 上移一層、Ctrl+Shift+] 移到最前，[ 反過來。
- **常用按鍵**：Ctrl+Z／Ctrl+Y 復原重做、Ctrl+C／Ctrl+V 複製貼上、Ctrl+D 再製、Delete 刪除、方向鍵微調（加 Shift 一次一格）。
- **看畫布**：畫布有真的捲軸——滾輪捲動（Shift+滾輪橫向）、拉捲軸也行，Ctrl+滾輪才是縮放，按住空白鍵或右鍵拖曳平移，工具列有「符合視窗」。紙的大小跟著圖走：把圖形拖出邊緣，畫布就往那邊長大。格線與「對齊格線」在「檢視」選單。
- **自動存檔**，選單列右邊會顯示「已儲存」。標題直接在最上面改，停手就存。離開的方式跟筆記一樣：點左上角的 StrikeNote 回首頁、點標題前面的資料夾回到那個資料夾，或按瀏覽器的上一頁。
- **一張圖就是一篇筆記**，所以改名、移動、垃圾桶、分享、備份都跟一般筆記一樣。右上角的「版本」可以看這張圖以前的樣子（兩張圖並排比較）並還原，「PDF」把這張圖印成 PDF。
- **放進報告裡**：在筆記的編輯器輸入 `/drawio`，挑一張畫過的圖，會插入 `![名稱](drawio:…)`。嵌的是參照不是複製，圖之後改了，引用它的筆記重新打開就是新的；匯出 PDF、出版成電子書都印得出來。
- **匯出**：工具列的 PNG／SVG 把整張圖存成圖片檔（白底），用到的圖示會一起包在檔案裡。
- 只有讀取權限的人看到的是那張圖，不會載入編輯器。

圖的內容存成一段看得懂的文字（一行一個圖形或一條連線），所以搜尋找得到、備份還原不用另外處理。畫布永遠是白底，深色主題下也一樣——印出來是白紙，畫的時候就該看到一樣的東西。

> 這個功能的第一版是把整套 draw.io 放進站內，後來改成現在這個自己做的版本。用第一版畫過的圖還看得到，但不能在這裡編輯。

### 關聯分析
新增 → 關聯分析，整頁的節點／連線畫布，用的就是 [React Flow](https://reactflow.dev/)：拖曳節點、從節點右邊的小圓點拉線到另一個節點、雙擊空白處新增節點、雙擊節點或連線改文字、選取後按 Delete 刪除、Ctrl+Z 復原，左下角縮放／鎖定、右下角縮圖，改動自動存檔。工具列的 **CSV** 選單可以「下載 CSV 範本」、「匯入 CSV」（也可以直接把 .csv 拖進畫布）自動產生整張圖並排版，或把目前的圖「匯出成 CSV」。格式是一列一條關聯：`source,target,label`（label 可以不填）。適合畫攻擊路徑、主機關聯這類不是樹狀結構的圖。

**點一下節點，跟它有關的線跟點會標出來**：連到它的線加粗、另一頭的節點維持原樣，其餘整片調暗（跟關聯圖同一套）。點空白處或按 Esc 取消。這只是畫面上的強調，不會寫進圖裡。

**便條紙**：工具列的「便條紙」會在畫面中央貼一張紙，直接打字寫備註（Enter 換行，點畫布空白處或按 Esc 收起來），雙擊或選起來按 F2 可以再改，拖著搬、按 Delete 刪掉。便條紙不是圖的一部分——連不到它，也拉不出線，而且畫在節點與連線的下面，所以蓋不掉圖。它會跟著圖一起存、一起印（預覽、PDF、電子書、嵌到別篇筆記都看得到）。

**線要往哪邊彎可以自己決定**：在連線上按右鍵，選「往左彎／往右彎／直線／自動」。沒特別指定時是自動分配（同一張圖每次畫都一樣，不會亂跳）；指定過的會寫進圖裡，所以預覽、PDF、電子書、嵌到別篇筆記都照你選的彎。也可以用 ` ```relmap ` 語法把一張圖嵌進任何一篇一般筆記裡，點「全螢幕」進去編輯。

**把畫好的關聯分析嵌到別篇筆記裡**：在筆記的編輯器裡輸入 `/relmap`，選一張你畫過的關聯分析就會插入 `![名稱](relmap:…)`。嵌進來的圖**可以用滑鼠拖曳平移、滾輪縮放**，右上角還有 `−` `＋` `重置` 跟「全螢幕」（跳到原圖去編輯）。嵌的是那張圖的**參照**不是複製：之後把原圖改了，所有引用它的筆記重新打開就是新的。匯出 PDF 或出版成電子書時會自動變成完整的一張靜態圖（工具列不會印出來）。
